# Offgrid Atelier

Static landing page prepared for GitHub Pages deployment.

## Deploy

1. Push the repository to GitHub.
2. In the repository settings, enable Pages.
3. Select `GitHub Actions` as the build and deployment source.
4. Push to `main` or trigger the workflow manually.

The site is fully static:
- `index.html`
- `styles.css`
- `script.js`

The workflow lives in [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml).
